## Verification methodology

For any answer in this log, the same method applies:

1. Run the command for that question again.
2. Look at the `found:` lines printed under each search layer — these list
   the exact document titles (or file names, for entries without a clean
   title) the agent actually retrieved.
3. Open those specific files in `data/raw/` and confirm the stated fact
   really appears in the text.
4. For conflict cases, confirm both competing claims genuinely exist in
   their respective source documents, and that the higher-reliability
   source really does contain the language used to justify the resolution
   (e.g., an explicit authority claim).

This is the same process used throughout development — every fix and every
result in this project was checked against real terminal output and real
source text, not assumed to work.
